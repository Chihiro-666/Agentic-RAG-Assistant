# 每周发布说明：v1.8.0

## 发布时间

本次版本于 2026 年 10 月 20 日发布，发布窗口为 22:00 到 23:30。

## 重要变更

### 文档上传

- 支持 Markdown、PDF、TXT 三种格式。
- 单个文件大小上限从 20MB 提高到 50MB。
- 上传失败时会显示具体原因，不再只显示“处理失败”。

### 检索

- 新增按文档来源过滤。
- 检索结果默认返回前 10 条，可通过 `retrieval.k` 调整。
- 相似度低于 0.25 的结果会被隐藏。

## 缺陷修复

### 修复登录页循环跳转

当浏览器禁用第三方 Cookie 时，登录成功后可能被错误跳回登录页。本版本已在同一站点内设置会话 Cookie，修复该问题。

### 修复大文件上传超时

上传超过 35MB 的 PDF 时，部分请求会在 60 秒后被网关中断。现在分片上传会在每片完成后更新进度，总超时时间延长到 10 分钟。

### 修复搜索结果重复

同一文档在不同时间被重复索引时，搜索结果可能出现重复。本版本使用文档指纹和版本号去重。

## 升级步骤

1. 备份数据库和对象存储。
2. 将服务镜像更新到 `v1.8.0`。
3. 执行数据库迁移脚本 `migrate_2026_10_20.py`。
4. 重启 API、Worker 和定时任务服务。
5. 打开 `/healthz`，确认返回 `ok`。

## 已知问题

- Safari 16 中，拖拽上传的进度条可能不刷新。
- 部分扫描版 PDF 的 OCR 准确率仍然较低。
- 中文全文检索对英文缩写的分词效果有限。

## 回滚方案

如果出现严重故障，将镜像回滚到 `v1.7.4`，并执行回滚脚本：

```bash
python scripts/rollback_2026_10_20.py --confirm
```

回滚不会删除新版本索引，但会停用新字段过滤功能。
