# API Gateway 常见问题

## 基础概念

### API Gateway 是什么？

API Gateway 是统一入口服务，负责请求路由、身份认证、限流、监控和协议转换。它可以让客户端不直接访问后端服务，同时为团队提供一致的安全策略。

### 支持哪些协议？

当前支持 HTTP/1.1、HTTP/2 和 WebSocket。gRPC 请求需要开启透传模式，目前仅在企业版提供。

## 认证与安全

### 如何获取 API Key？

登录控制台，进入“项目 > 密钥管理”，点击“创建 API Key”。密钥只会完整显示一次，请立即保存。测试环境密钥以 `test-` 开头，生产环境密钥以 `live-` 开头。

### 请求头应该怎么写？

所有请求需要携带：

```http
Authorization: Bearer <access-token>
X-Api-Key: <api-key>
X-Request-Id: <unique-request-id>
```

`X-Request-Id` 最长 64 个字符，推荐使用 UUID。没有该请求头时，网关会自动生成，但排障效率会降低。

### 令牌有效期多久？

Access Token 默认有效期为 2 小时。Refresh Token 有效期为 30 天，且只能使用一次。刷新成功后会返回新的 Access Token 和 Refresh Token。

## 限流

### 默认限流规则

| 套餐 | 每秒请求数 | 每日请求数 | 并发连接 |
|---|---:|---:|---:|
| Free | 20 | 10,000 | 50 |
| Standard | 200 | 500,000 | 500 |
| Enterprise | 自定义 | 自定义 | 自定义 |

超过限流阈值后，网关返回 HTTP 429。响应头中的 `Retry-After` 表示建议等待秒数。

### 如何提高限流？

可以在“配额管理”中提交临时扩容申请。临时扩容最长 30 天。长期扩容需要升级套餐或联系商务。

## 错误码

### 401 Unauthorized

表示认证失败。请检查 Token 是否过期、签名是否正确、API Key 是否被禁用。

### 403 Forbidden

表示身份有效但没有权限。确认账号是否已开通对应 API，以及 API Key 是否绑定到正确项目。

### 504 Gateway Timeout

后端服务未在 15 秒内返回结果。请优化慢查询、增加超时重试，或联系后端负责人检查服务状态。

## 监控

网关会记录请求路径、状态码、耗时、调用方 ID 和错误码。日志默认保留 7 天，付费版可延长到 30 天。

可以配置以下告警：

- 5xx 比例连续 5 分钟超过 1%
- P99 延迟连续 5 分钟超过 800ms
- 每分钟 429 请求数超过 100
