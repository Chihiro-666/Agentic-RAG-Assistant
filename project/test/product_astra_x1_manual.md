# Astra X1 智能投影仪用户手册

## 产品概述

Astra X1 是一台面向家庭和轻办公场景的智能投影仪。它采用三色激光光源，标准分辨率为 1920×1080，支持 4K 输入解码。官方标称亮度为 2200 ANSI 流明，对比度为 2000:1。

设备内置 Android TV 12 系统，支持 Wi-Fi 6、蓝牙 5.2、HDMI 2.1 和 USB 3.0。整机重量约为 3.1 千克。

## 首次安装

1. 将投影仪放置在稳定平面上，镜头距离幕布或白墙 1.2 到 3.5 米。
2. 连接电源后，长按机身右侧电源键 2 秒。
3. 首次启动时，按照屏幕提示连接 Wi-Fi。
4. 登录账号后，系统会自动检查固件更新。
5. 如画面倾斜，使用遥控器进入“设置 > 画面 > 梯形校正”。

镜头到 100 英寸画面的推荐距离约为 2.6 米。夜间建议开启低亮度模式以减少风扇噪音。

## 遥控器按键

| 按键 | 功能 |
|---|---|
| 电源 | 开机、关机或进入待机 |
| Focus | 触发自动对焦 |
| Keystone | 打开梯形校正菜单 |
| Voice | 按住后说出指令 |
| Input | 切换 HDMI、USB 和系统输入源 |

## 常见问题

### 无法开机

请确认电源线插入牢固，插座正常供电。长按电源键 10 秒可强制重启。如果指示灯持续红色闪烁，请停止使用并联系售后。

### 没有声音

检查是否开启了静音模式。进入“设置 > 声音 > 输出设备”，确认输出到机身扬声器、蓝牙音箱或 HDMI 音频。若使用蓝牙音箱，请重新配对。

### 画面模糊

按遥控器 Focus 键触发自动对焦。如果仍有模糊，检查镜头是否有灰尘，并使用干燥镜头布清洁。不要使用酒精直接擦拭镜头。

## 保养与售后

建议每 3 个月清洁一次进风口和出风口。避免在温度超过 40℃ 或低于 0℃ 的环境中长时间使用。

整机保修 2 年，光源保修 5 年。人为损坏、进水、私自拆机不在保修范围内。售后热线为 400-820-9911。
